### Open Source

These four projects share a thesis: **AI systems need verifiable security, and security systems need local-first autonomy.** Each one addresses a piece of that — from testing LLM defenses to running your entire stack on hardware you control.

| Project | What it does |
|---------|-------------|
| [Agent Conclave](https://github.com/tannernicol/agent-conclave) | Multi-model consensus engine — fan queries to N models, cross-validate reasoning, converge on verdicts with audit trails |
| [Grimoire](https://github.com/tannernicol/grimoire) | Hybrid FTS5 + vector search over security knowledge (CVEs, CWEs, OWASP), served via MCP for agent-native retrieval |
| [Ollama Says](https://github.com/tannernicol/ollama-says) | Prompt injection testing harness — 37 attack vectors, 8 signal detectors, CVE reproduction labs, fully offline |
| [Helm Suite](https://github.com/tannernicol/helm-suite) | Replace 5 SaaS products with one Linux box — Tailscale-scoped, zero-public-ingress self-hosted stack |
